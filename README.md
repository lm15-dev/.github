### Icons

Square icons in standard sizes for favicons, Apple Touch, Android Chrome, and Microsoft tiles live in [`assets/icons/`](assets/icons/).

### Banners

Wide-format images for social sharing and README headers live in [`assets/banners/`](assets/banners/).

| File | Size | Use |
|------|------|-----|
| `banner-1200x300.png` | 1200×300 | README header |
| `banner-600x200.png` | 600×200 | Email / compact |
| `og-image-1200x630.png` | 1200×630 | Facebook / LinkedIn |
| `twitter-card-1200x600.png` | 1200×600 | Twitter / X |
| `github-social-1280x640.png` | 1280×640 | GitHub social preview |

### Usage in READMEs

```markdown
<p align="center">
  <img src="https://raw.githubusercontent.com/lm15-dev/.github/main/assets/banners/banner-1200x300.png" alt="lm15" width="600">
</p>
```
